# VillaForge 1.50.0

## GitHub-Changelog-Agent

- Nimmt GitHub `push` Webhooks unter `/api/v1/webhooks/github` entgegen.
- Verifiziert `X-Hub-Signature-256` mit HMAC-SHA256 anhand des unveränderten Request-Bodys.
- Verarbeitet Delivery-IDs idempotent und gibt Telegram-Fehlerclaims für GitHub-Retries frei.
- Erstellt kostenlose, strukturierte Changelogs aus Commit-Metadaten und gruppiert Conventional-Commit-Typen.
- Sendet Klartext via Telegram Bot API ohne Markdown-Auswertung und begrenzt die Nachricht auf sichere Länge.
- Secrets liegen ausschließlich in Laufzeitvariablen; der Gateway-Status zeigt die Konfiguration ohne Werte.

## Einrichtung

```dotenv
GITHUB_WEBHOOK_SECRET=<dasselbe Secret wie in den GitHub-Webhook-Einstellungen>
TELEGRAM_BOT_TOKEN=<Bot-Token aus BotFather>
TELEGRAM_CHAT_ID=<Zielchat des Bots>
```

GitHub Webhook: `POST /api/v1/webhooks/github`, Content-Type `application/json`, Ereignis `push`.
Der Status unter `/api/v1/webhooks/status` zeigt die Integration als `konfiguriert` oder `deaktiviert`.

## Prüfung

Signaturprüfung, Manipulationsschutz, Changelog-Kategorisierung, Telegram-Fehlerpfad und Nachrichtengrenze sind mit Unit-Tests abgedeckt. Vor Release laufen die vollständige Hub-Test-Suite, Syntax- und Secret-Prüfungen.
