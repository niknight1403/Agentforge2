## VillaForge 1.57.6

### Ressourcen-Druck realistisch bewertet

- Die Druckanzeige reagierte auf einzelne CPU-Spitzen (Build, Inferenz-Burst, Modell-Download) mit CRITICAL und drosselte die Parallelitaet auf 1 Slot — Villen standen dann minutenlang auf "wartet auf freien Rechen-Slot", obwohl Arbeit moeglich war.
- Neu: Hysterese ueber zwei Messungen in Folge; CRITICAL nur bei anhaltender Saettigung oder akutem Speicherdruck. Zusaetzlich wird die Last pro Kern (load1/Kerne) bewertet, nicht nur der Moment-CPU-Wert.

### Event-Loop atmet

- Der Villen-Batch-Loop bekommt nach jeder Runde ein 300-ms-Yield. Damit teilen sich Laeufe, Scheduler, SSE und API den Node-Thread fair; ein laufender Batch blockiert keinen Kern mehr dauerhaft.

### Release und Qualitaet

- Hub-, npm- und Android-Version auf 1.57.6 synchronisiert; Android versionCode 58.
