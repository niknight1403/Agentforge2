# VillaForge 1.45.0

VillaForge 1.45.0 synchronizes the Android and Hub versions and ships a
cost-conscious AI routing default with a tested, repeatable APK release path.

## Highlights

- Gemini Flash-Lite is the default cloud model. Failover tries approved free
  Groq models, free OpenRouter models, and local Ollama or LM Studio routes.
- Paid, credit-based, and unknown providers are skipped by default. Set
  `VF_LLM_FREE_ONLY=0` only when paid routes are intentionally allowed.
- The route status API now reports eligibility using the same policy as actual
  requests. Existing stale Gemini and Groq defaults migrate to current models.
- Deep Agent briefs set clear deliverables and acceptance criteria. Bounded
  text attachments enter the model context; unsupported binary content is
  identified rather than claimed as reviewed.
- LLM outages are reported honestly and do not produce fabricated completion
  claims.
- A `v*` tag runs Android unit tests, builds the installable APK, and publishes
  that exact tested APK with these release notes.

## Validation

- Hub test suite: 155 passed.
- Android unit tests and APK build: run by the tag release workflow.

## Notes

Free provider quotas are limited and vary by account. Gemini free-tier prompts
may be used by Google to improve products; do not submit confidential source
code or customer data through that route. The Android APK is debug-signed for
direct installation and is not a Play Store signing artifact.
