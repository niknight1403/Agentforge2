# VillaForge 1.46.0

VillaForge 1.46.0 verbessert die tägliche Arbeit mit Projekten und bringt die Web-Oberfläche und Android-App auf eine ruhigere, klarere Produkterfahrung.

## Highlights

- Responsives Dashboard mit einer breiteren, strukturierten Arbeitsfläche auf Desktop-Geräten.
- Villen können in Übersicht und Chat-Auswahl nach Name und Beschreibung durchsucht werden.
- Weniger Neon-Glühen, bessere visuelle Hierarchie, klarere Fokuszustände und gut erreichbare Touch-Ziele.
- Vereinheitlichte, gedämpfte Akzentfarben in Web und Android.
- Die unbelegte „ELITE · UNLIMITED“-Anzeige wurde entfernt und durch „PROJEKTSTUDIO · DEEP AGENT“ ersetzt.

## Validation

- Hub test suite: 155 passed at v1.45.0; CI checks run for this update.
- Android unit tests and release build run by the pull request checks.
