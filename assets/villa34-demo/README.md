# Villa 34 – Demo-Assets

Dieses Verzeichnis enthält sechs weboptimierte, eigens für die Villa-34-Demo erzeugte Bilder: drei Porträts fiktiver erwachsener Charaktere (28+) und drei nicht-personenbezogene Szenenhintergründe. Die Porträts zeigen vollständig bekleidete, nicht-explizite Personen; sie stellen keine realen Menschen dar und verwenden keine fremden Marken oder Website-Bilder.

Die Dateien sind lokal in die App zu kopieren und nicht als Hotlinks auf externe Bildanbieter einzubinden. Für die Szenen-Auswahl enthält dieses Paket Lese-Lounge, Gewächshaus und Kunststudio; ein zusätzlicher neutraler Szenenstil kann direkt in der UI umgesetzt werden.

Die JPEGs wurden für Web-Nutzung auf 900×1200 px (Porträts) bzw. 1600×900 px (Szenen) optimiert. `manifest.json` enthält IDs, Alter, Rollen und barrierearme Alt-Texte.
