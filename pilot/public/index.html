Was AnfragePilot fuer Sie tut

Gebaut fuer Betriebe, die Anfragen per E-Mail, Formular oder Marktplatz bekommen und keine Zeit fuer Routineantworten haben.

Antwort vorschreiben

Eine Antwort, die Sie so absenden koennen — Stil und Ton passen zur Anfrage.

Anfragen sortieren

Angebot, Termin, Reklamation, Preisfrage oder Support: jede Anfrage bekommt eine Kategorie.

Dringlichkeit erkennen

Reklamationen und Fristen landen oben statt im Stapel.

Nichts erfinden

Fehlen Preise oder Termine, fragt der Entwurf gezielt nach — statt Zahlen zu raten.

Per API anbinden

Formular, Postfach oder CRM: ein POST-Request, Antwort als JSON.

Kontrolle bleibt bei Ihnen

Jeder Entwurf wird geprueft. Gesendet wird nur, was Ihr Team freigibt.

Eine Anfrage, eine Antwort

Der Endpunkt nimmt eine Nachricht und liefert eine versandfertige Antwort mit Einordnung.

curl -X POST https://IHR-HOST/api/v1/reply \
  -H "X-API-Key: ap_..." \
  -H "Content-Type: application/json" \
  -d '{"nachricht":"Wir brauchen ein Angebot fuer 12 Telefone. Wann koennen Sie kommen?"}'

{
  "reply": "Guten Tag, ...",
  "kategorie": "angebotsanfrage",
  "dringlichkeit": "hoch",
  "naechster_schritt": "Anzahl Nebenstellen und zwei Termine erfragen",
  "meta": { "provider": "groq", "latenz_ms": 940, "frei": 187 }
}

Jeder Aufruf zaehlt eine Anfrage aus Ihrem Monatskontingent. Fehlerhafte Anfragen zaehlen nicht.
